 **Calculator | CodeAlpha**

A simple, responsive, and interactive **Calculator Web Application** built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship – Task 2**.

**Project Description**

This project is a basic web-based calculator that performs common arithmetic operations through a simple and user-friendly interface.

Users can enter numbers using the calculator buttons or their keyboard, perform calculations, clear the display, delete individual inputs, and view results instantly.

 **Features**

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input
* 🧹 Clear functionality
* ⌫ Delete/Backspace functionality
* 🟰 Instant calculation and result display
* ⌨️ Keyboard support
* 📱 Responsive design
* 🎨 Modern and user-friendly interface
* ⚡ Button hover and click effects

 **Technologies Used**

* **HTML5** – Used to create the structure and layout of the calculator.
* **CSS3** – Used for styling, responsive design, spacing, animations, and visual effects.
* **JavaScript** – Used to implement calculator logic, handle user input, perform arithmetic operations, and update the display.

  **How It Works**

1. The user enters numbers using the calculator buttons or keyboard.
2. JavaScript captures the user's input.
3. The selected arithmetic operator is processed.
4. The calculator performs the required calculation.
5. The result is displayed on the calculator screen.
6. The **Clear** button resets the calculator.
7. The **Delete/Backspace** functionality removes the last entered character.
8. Keyboard support allows users to operate the calculator without clicking the buttons.

 **How to Run the Project**

 **Method 1 – Open Directly**

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The calculator will open in your web browser.

 **Method 2 – Using Visual Studio Code**

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Run the project using a browser or the **Live Server** extension.
4. Start using the calculator.
